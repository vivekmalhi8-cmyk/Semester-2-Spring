# Semester 2 — Spring

A collection of coursework, lab materials, and programming exercises from my second-semester spring term. The repository brings together practice work from C++ and related computer science subjects.

## Highlights

- C++ exercises, including pattern practice and introductory programming tasks
- **PakWheels marketplace prototype** — an object-oriented C++ exercise modeling users, vehicles, listings, favorites, and basic marketplace interactions
- Lab and course materials, including documents for OOP and Digital Logic Design

## Getting started

Browse the repository to locate the source file or course material you need. The C++ files are standalone exercises unless a file explicitly includes a related header. For a standalone source file, compile with a C++ compiler such as GCC:

```bash
g++ -std=c++17 "Task 1.cpp" -o task
./task
```

Replace the filename with the exercise you want to build. For projects split across multiple source files, compile all required `.cpp` files together and keep their headers in the expected locations.

## Repository guide

- `.cpp` and `.h` files contain programming exercises and project code.
- `.docx` files contain course and lab materials.

## Project status

Educational coursework and practice. Examples may be incomplete or change as the material is revisited; they are not intended as production software.
